// The Deep Market: the crossroads town the sparse network implies. 71x49,
// 2374 carved / 1105 masonry as drawn (footprint 2.07x the retired Hearth,
// and deliberately NOT square -- rotation hands out portrait and landscape
// markets). West half: two crate-stacked warehouses over the grand trade
// hall; east half: the stall-rowed market yard over the shop terraces.
//
// THE DOOR RULE, measured, do not shorten: every door, passage, stall gap and
// grave-row gap is THREE cells long in its run direction. The wall drape seals
// 2-long gaps that rotation turns east/west -- the Hearth's v2 draft lost a
// 45-cell interior to that, and this set's market draft lost a 66-cell stall
// lane to 2-wide stall gaps before the rule was applied to furniture too.
// Validated through the real builder in all eight orientations, before and
// after five-wide road cuts on four headings: zero pockets, zero
// fragmentation.
//
// One of the authored DwarvenVillage plans is rolled seeded at floor-3
// generation (PlaceVillage); drop another file with this archetype beside
// these and it joins the rotation with zero configuration.
