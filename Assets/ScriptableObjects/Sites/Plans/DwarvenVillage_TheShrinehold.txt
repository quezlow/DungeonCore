// The Shrinehold: the old-faith village, entry 20's deep faith on screen.
// 61x61, 2588 carved / 1133 masonry as drawn (footprint 2.21x the retired
// Hearth). North-west and south-west: cloister terraces and the refectory;
// north-east: the shrine precinct, votive pillars ringing an inner sanctum
// with its altar; south-east: the bell court, belfry, keeper's house and
// the grave rows.
//
// THE DOOR RULE, measured, do not shorten: every door, passage, stall gap and
// grave-row gap is THREE cells long in its run direction. The wall drape seals
// 2-long gaps that rotation turns east/west -- the Hearth's v2 draft lost a
// 45-cell interior to that, and this set's market draft lost a 66-cell stall
// lane to 2-wide stall gaps before the rule was applied to furniture too.
// Validated through the real builder in all eight orientations, before and
// after five-wide road cuts on four headings: zero pockets, zero
// fragmentation.
//
