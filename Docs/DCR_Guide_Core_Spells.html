Core Spells

Canon 38 — the core acts directly. Three neutral workings researched down the Sorcery path, one affinity working handed down by your god and deepened twice. Cast at a cell, over a radius, priced in mana and held back by a cooldown.

1. What shipped, in one breath

A fifth action-bar tab (CAST, default X) puts BuildMode.CastSpell on the bar. Click a cell; SpellCaster resolves the effect over SpellBook.EffectiveRadius; mana and cooldown are stamped only if something actually happened. Spell assets live in Resources/Spells and SpellBook loads them itself — no registry asset, no Inspector drag.

Two channels, and the fiction is the reason. A core cannot research its god's own power; it is given. The Sorcery path holds only the neutral craft — Lash, Knit, Call to Arms — which is why it is three nodes and not twelve. It is half a path by design, and the other half arrives at a tier-up audience.

2. Scene wiring, and the order it has to happen in

Five slots on ActionBarHUD, all of them assigned as of the Spell wiring commit. Recorded because the next person to touch this bar — or a second scene — needs to know what the row expects.

SlotWhat it is
castTabButtonFifth tab Button. Leave it ACTIVE — RefreshCastTabVisibility drives its active state and switches it off itself. A tab left inactive works but never appears until the first roster change, which looks exactly like a bug.
spellEntryContainerTransform with a HorizontalLayoutGroup, inactive by default. The container IS the panel — showing the row toggles this GameObject, exactly as the mine gesture row does.
spellDetailLabelOptional TMP_Text. Follows the POINTER, not the selection: shown on hover, hidden on exit.
submenuEntryPrefabAlready assigned — the row deliberately shares the Build and Mine entry prefab, so it matches them with no extra art.
spellUnaffordableColorEntry tint when the core cannot pay. Selected and unselected reuse the bar's existing two.
The tab stays hidden until the core holds a working. It lights on SpellBook.AnySpellKnown, not on the Sorcery trunk — a god's grant must be reachable by a core that never researched the trunk. So until step 1 has run and a key is set, there is no CAST tab and no visible hotkey. That is the design, but it is also the first thing to check when it looks like nothing shipped.

4. The recipe: adding a working

One entry in Editor/SpellContentGenerator.cs, then the menu item. The generator is authoritative the way TechContentGenerator is for nodes: a hand-made asset in the folder loads and works, but the next person to read the generator will not know it exists.

new SpellSpec
{
    assetName = "Spell_Whatever", id = "whatever", displayName = "Whatever",
    effect = SpellDefinition.SpellEffect.Lash,
    requiredUnlockKey = "tech.some_node",   // or "spell.whatever.t1" if a god gives it
    deepeningKeyBase = "",                  // "spell.whatever" only if it deepens
    affinity = DungeonType.None,            // None = every core may hold it
    manaCost = 12f, cooldownSeconds = 4f,
    radius = 2.0f, durationSeconds = 0f, magnitude = 10f, secondary = 0f,
    castableWhilePaused = false,
    description = "One line, wisp-adjacent, in the core's register.",
},
5. The Sorcery path, and why it is short

Three nodes in Editor/TechContentGenerator.cs: The First Spark (t1, 20pts/3d), The Drawn Breath (t2, 30/3) and Call to Arms (t2, 25/2). The trunk is prereq'd on Whispers of Intent — Observation's tier 3 — so the last path costs breadth to reach at all, which is canon 13's stated intent for cross-path prerequisites.

6. Writing for a god that gives something

Insert now carries grantsUnlockKey and grantLine beside the god's own line for that tier. The grant is authored beside the words that announce it — there is no second list of grants anywhere, because a second list is a thing that drifts.

7. Decisions worth not re-litigating
One thing still undecided. AdventurerParty.Fracture exempts Heroes from morale breaks; Terror does not, so a named Hero will rout. That was left deliberately — unlike capture, a rout is temporary and self-pricing, since they leave alive with your loot and your notoriety. But it is inconsistent with the morale rule. One line in ForceRetreat if you want them exempt.
