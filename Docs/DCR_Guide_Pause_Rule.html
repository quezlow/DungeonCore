The Pause Rule

Canon 39 — the availability audit. One sentence, applied to every action a player can reach: pause permits deciding; it forbids acting. Eleven files agreed to it, three of them backwards.

1. What the audit found

Canon 38 stated a pause rule and declared the audit closed. It was never applied. Sweeping every player-reachable action against it turned up three distinct defect classes.

Five commits ran freely while the world was held. Research, trade, the crypt raise, the three prisoner verbs, the three caravan verbs. The crypt was the sharpest: pause mid-raid, raise skeletons, unpause.

Three openers refused while held even though opening a panel is navigation, which the rule permits — the room anchor click, the trap panel hotkey, the crypt corpse click.

Two of those were inverted. Pausing before you clicked locked you out; pausing after left every button behind the panel live. Exactly backwards, and precisely the class of bug an audit exists to catch.

The old wording did not survive contact. Canon 38 forbade “anything that spends mana or changes world state”. But research spends and does not act, trade spends and does not act, and a prisoner's release spends nothing and plainly does. The test is what an action reaches, not what it costs.

2. The rule

Pause permits DECIDING. It forbids ACTING.

Deciding — permitted while heldActing — forbidden while held
Selection, deselection, camera, floor changeMine, dig-queue drain, build wall, demolish
Orders: patrol, attack-here, post, right-click movePlace: entrance, spawner, chest, furniture, anchor, trap, stairs, core
Browsing any panel, reading any stateCrypt raise, prisoner release/execute/interrogate
Research: browse and commitCaravan rob/tax/let-pass, bribe
Trade: browse and buyRoom retype, delete, upgrade
Ghosts and the hover cost preview, every modeSpells, except those flagged castableWhilePaused

Acting means reaching an entity standing on the board or a cell of the tilemap: placing, removing, spawning, damaging, healing, retyping, channelling. Deciding is everything else, including commitments that touch nothing but a ledger.

Why research and trade are on the permitted side. Research is pre-paid, refunded in full on cancel, and its progress runs on the day clock — which stops with everything else. Committing while frozen confers no advantage whatever. It is a planning screen and it behaves like one. A purchase is a ledger swap; the goods arriving are its consequence, not its act. Both are named in canon rather than left to be re-derived, because both look like spends and neither is one.

3. Gate the action, never the opener

This is the whole shape of the fix, and the reason the inversions cannot recur. Every panel opens, browses and inspects while the world is held. Only the button that commits refuses.

New file Assets/Scripts/Data/PauseGate.cs carries it:

PauseGate.Held                      // world frozen?
PauseGate.CanAct(out string reason) // may I act, and why not
PauseGate.RefuseAt(worldPos)        // toast + return true if refused
PauseGate.RefuseAtCore()            // for a bare HUD button

Call sites read as a single guard line:

if (PauseGate.RefuseAt(piece.transform.position)) return;

A refusal speaks in the wisp's voice rather than failing silently. Where a button can be greyed ahead of the click, it is — the crypt raise and the bribe both go dim while held, so the refusal is visible before you spend a click on it.

A refusal never burns a decision. The caravan verb refuses before the panel closes, so the choice survives it and the wagon stays halted — the same ruling that already protected a misclick from spending the one verb.

4. Two defects folded in

The inspector's notice no longer steals your speed. Dismiss() called SetNormal(), which quietly demoted a player running at 5x and force-unpaused a player who had paused deliberately before the Inspector arrived. This is the identical defect canon 19A named for the divine audience, sitting in a second place. Announce now records whether the notice was the thing that took the clock, and Dismiss restores through PauseController.UnpauseGame only when it was.

The bribe itself stays forbidden while held. Both fuses it pays off run on scaled time, so the notice pauses in order to be read, and the coin is offered once the world runs again.

Ghosts draw while held. The mine highlight and the wall ghost both hid themselves while paused, so a frozen board could not be planned against. They now draw, following the spell ghost's precedent from canon 38. A dig target you cannot see is a dig you cannot plan.

5. The hover cost preview is finished (polish item p)

It shipped for walls only — its own comment said so. It now covers every costed mode, through one label owned by UpdateCostPreview and parented to the build controller rather than to the wall ghost it outlived.

ModeShows
MineMana at the effective claim multiplier, not the authored base — granite bills more, and a preview showing the base price is a preview that lies
Build wallMana, over the resolved cap where the column will rise
Trap, spawnerMana and capacity
Chest, furniture, stairs, spellMana
DemolishThe half-mana refund, in green. Nothing at all over a room anchor, which refunds nothing
Entrance, order modesNothing — they cost nothing

Unaffordable reads red. In Mine mode the label carries a second line with the standing dig queue's cell count and total mana, priced per cell on its own floor's multiplier — the queue is precisely what gets built on a frozen board, and its price is invisible anywhere else.

The pause fix and this feature are the same edit. Line 1102 killed the whole wall ghost while paused, label included. Ungating it lands the preview pause-visible for free — which is the entire point of costing a board you have deliberately frozen.

6. The register lives in code

Commands → Print Pause Audit prints the live hold state, the rule, and every reachable action with its ruling, plus which spells are flagged pause-legal.

The audit existed because eleven files had to be swept to discover what the rule even was. A new action belongs in that table the day it is written.

Ambiguous defaults were avoided deliberately. The pause-legality of a spell stays a serialized castableWhilePaused bool, not a property derived from the effect enum, exactly as canon 38 set it — so a future order-spell cannot become silently pause-illegal.

8. A shelved feature with a case

Surfacing rather than forcing, per the working convention.

Specials / one-shot consumable effects (deferred item 15, still undecided). The pause rule now draws a clean line between deciding and acting, and a consumable is the one thing that sits awkwardly across it — a held one-shot is a decision, spending it is an act. If that feature is ever taken up, canon 39 is the frame it should be designed against, and its pause-legality should be an explicit serialized flag like castableWhilePaused rather than anything derived. Not a reason to build it now.

The other two thirds of the Phase 9 polish trio remain open and untouched: (q) the per-trap fire counter and (r) the placement preview ghost. Item (p) is now closed.
