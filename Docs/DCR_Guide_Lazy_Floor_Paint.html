2. The Rule and the Five Locked Forks

The rule, one sentence: the fog disc still paints in full at GenerateAt; the floor tile is laid per cell inside RevealTile, the moment fog lifts, and nowhere else.

1. Trigger — on reveal. Every reveal path already funnels through RevealTile: claims, the starter blob and its border, mining halos, feature reveals, and the load restore sweeps (silent ClaimTile, the mined sweep, UnfogAllRevealedFeatures). Rivers and roads already paint lazily on reveal with load-path repaint sweeps, so the floor tile joins the house pattern. Camera-proximity and chunk-on-demand were rejected: fog hides unrevealed pixels, so both paint invisible work.

2. Fog stays eager. Fog-tile absence is the revealed flag — FloorRoot.IsRevealed reads it, and ReachabilityDirector, the minimap and DeadCoreSaturation read that. Fog is also the per-cell tint substrate for the road feather and the floor-0 rim gloom. Re-founding IsRevealed on a set was rejected as reveal-semantics surgery for the remaining half.

3. Floor 0 stays fully eager. Its rim facade unfogs around RevealTile and PaintRimGround deliberately clears rim floor tiles. This also stays clear of entry 24's standing rejection of staged tile painting, which is about the surface bands where the confiner ceiling is the only void guard (Appendix C); the disc differs because fog covers everything unrevealed and the camera bound is radius-derived.

4. Load is lazy by the same single rule. The restore sweeps re-reveal every revealed cell through RevealTile, which repaints exactly that set. Order against paving is proof by construction: paving overwrites unconditionally at ApplyRuinsOverrides, reveal paint skips any cell already holding a floor-layer tile.

5. Eviction: never. Paint-once-forever, mirroring the FOG IS ONE-WAY ruling in DungeonTerrain's header.

Walkability is untouched, by construction

Walkability is born in TileInfluenceManager's claimed/mined sets and read by DungeonPathfinder.IsWalkable; no tilemap is consulted anywhere on that path. This change moves pixels only.

3. What the Script Changes

DungeonCore/DungeonTerrain.cs

GenerateAt sets lazyFloorPaint (every floor but 0). PaintTerrain becomes two calls to a new single-layer PaintDiscLayer — fog always, floor only when eager — timed apart when LogBootstrapTimings is on. RevealTile gains one line: EnsureFloorPainted(pos), which no-ops on eager floors and outside the disc, skips any cell already holding a floor-layer tile (the paving rule), lays the plain tile otherwise, and keeps four counters plus a cumulative-ms tally. Accessors expose the lot to the log line and the validator.

Floors/FloorRoot.cs

The bootstrap log line splits its terrain bucket: terrain N ms (fog X ms, floor Y ms), printing floor deferred on lazy floors.

Floors/TerrainFeatureGenerator.cs

ApplyRoadFogFade calls EnsureFloorPainted for every cell it thins below solid alpha — the one place a cell shows through fog without being revealed — so the gauze thins onto ground, not void. The old paving NOTE is resolved in place. BuildRevealConsistencyReport gains two audits that weigh into FAIL — revealed cell with no floor tile (miss) and plain disc tile under solid fog (leak; paving under fog is exempt, feather cells exempt by alpha) — plus a per-floor counters line.

Docs/DESIGN_CANON.md

Entry 47 inserted before the Appendix; entry 19's paving rider struck and amended in place; TOC gains 45/46 (drift hygiene) and 47.

6. Diagnostics Reference

painted-on-reveal — cells whose plain floor tile was laid by the reveal hook. skipped-existing — reveals that found a tile already there (paving, or a cell revealed twice via overlapping halos). outside-disc — halo reveals past the disc edge; a no-op, mirroring fog. reveal-paint total — cumulative ms inside EnsureFloorPainted since the floor was created or loaded.

FAIL classes added to the validator: revealed cell with NO floor tile means some path unfogged without going through RevealTile on a lazy floor — the miss class this whole design guards against; plain floor tile under SOLID fog means something painted without revealing — the leak class. Both print sample coordinates under the existing detail format.
